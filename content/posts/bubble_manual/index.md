기밀 등급: **사내 회람용**  
배포처: 백일몽 주식회사 압착 사업부 전 사원

---

## 들어가며

당신은 방금 압착 사업부에 배속되었다.

업무는 단순하다. **뽁뽁이를 터뜨려 압축 공기(ml)를 회수하는 것.** 상단바에 떠 있는 회색 기포들이 당신의 일감이다. 스무 번쯤 터뜨리고 나면 왼쪽에 리모콘이 나타난다 — 그때부터가 진짜 시작이다.

압축 공기는 곧 실적이고, 실적은 곧 직급이다.

---

## 1. 기본 압착 (수동)

기포를 클릭하면 압축 공기가 회수된다. 처음엔 회당 1ml. 별거 아니어 보이지만, 모든 대표이사도 여기서 시작했다.

- **기포 부피 확장** — 회당 회수량을 늘린다. 가장 먼저 손대는 강화.
- **표면 장력 강화** — 확률적으로 5배가 터진다. `CRITICAL!`이 붉게 뜨면 그날은 운이 좋은 날이다.

## 2. 자동화 (자리를 지키지 않아도 되는 경지)

손목이 아프기 시작하면 자동화를 도입할 때다.

- **공기 자동 주입기** — 초당 자동 회수. 가만히 있어도 실적이 쌓인다.
- **연쇄 뽁 공명장** — 2초마다 알아서 기포가 터진다. 커서 근처는 피해서 터지니, 당신의 수동 클릭을 방해하지 않는다.
- **압력 전파 충격파** — 한 번 클릭하면 주변 기포까지 연쇄로 터진다. 레벨이 오를수록 반경이 넓어진다.
- **뽁뽁이 재생력 강화** — 터진 기포가 더 빨리 되살아나고, 화면에 떠 있는 기포 수 자체가 늘어난다.

## 3. 고급 사업 (신설 부서)

압착 사업부가 최근 신설한 세 부서다. 여기서부터가 진짜 대기업이다.

- **황금 압착기** — 가끔 <span style="color:#ffd700; font-weight:bold;">반짝이는 황금 뽁뽁이</span>가 등장한다. 8초 안에 터뜨리면 대량 보상. 놓치면 사라진다. 레벨이 오를수록 자주 나타난다.
- **심야 컴프레서** — 퇴근한 사이에도 컴프레서가 돌아간다. 다시 접속하면 자리를 비운 동안(최대 8시간분) 쌓인 공기를 정산받는다. **오프라인 수익**.
- **공명 증폭기** — 모든 회수량에 배율이 붙는다. 레벨당 +25%. 후반 실적을 폭발시키는 열쇠.

---

## 4. 직급 체계

누적 회수량에 따라 사원증의 직급이 갱신된다. 소비한 공기는 직급 판정에서 빠지지 않으니, 마음껏 강화에 투자해도 된다.

| 누적 압축 공기 | 직급 |
| --- | --- |
| 0 ml | 수습 뽁뽁 견습생 |
| 100 ml | 뽁뽁 사원 |
| 1,000 ml | 뽁뽁 주임 |
| 10,000 ml | 뽁뽁 대리 |
| 100,000 ml | 뽁뽁 과장 |
| 1,000,000 ml | 뽁뽁 차장 |
| 10,000,000 ml | 뽁뽁 부장 |
| 100,000,000 ml | 뽁뽁 이사 |
| 1,000,000,000 ml | 뽁뽁 대표이사 |
| 10,000,000,000 ml | 전설의 압축 공기 마스터 |

리모콘의 진행도 바가 다음 직급까지 얼마나 남았는지 알려준다.

## 5. 업적

특정 조건을 달성하면 사내 표창(업적)이 리모콘 하단에 기록된다. 첫 뽁부터 9종 강화 완비까지 — 전부 모으는 게 압착 사업부 사원의 로망이다.

---

## 사내 공략 요령

1. **초반엔 기포 부피 확장** 위주로. 회당 회수량이 곧 성장 속도다.
2. 실적이 좀 쌓이면 **자동 주입기 → 연쇄 공명장** 순으로 자동화를 깐다.
3. **황금 압착기**는 여유가 생기면 반드시 사둔다. 황금 뽁 한 방이 수동 클릭 수백 번을 대신한다.
4. 자주 자리를 비운다면 **심야 컴프레서**가 효자다.
5. 후반엔 **공명 증폭기**에 몰빵. 배율은 곱연산이라 후반 체감이 가장 크다.
